# Precise

Instrument-grade. Every pixel accounted for.

Exact values: run `node scripts/feel.js precise` (intensity 1 to 3 with `--intensity`).

## Signature moves

- Fast (140 ms), critically damped spring (700 / 45): no settle at all.
- Small radius (4 px), hairline shadow (1 / 2 px at 8%).
- Tight scale (1.125), high contrast (95% ink), compact padding (12 px).

## Do

- Align everything to a 4 px grid; use tabular numbers.
- Great for data, tools, editors, settings.

## Don't

- Soft blurry shadows or big radius.
- Any overshoot or wobble.

**Blends well with:** bold, premium, quiet.
**Pulls against:** playful, soft. Blending is allowed; the engine averages each value, so the result sits between the two.
