# Soft

Pillowy and gentle. Rounded everything.

Exact values: run `node scripts/feel.js soft` (intensity 1 to 3 with `--intensity`).

## Signature moves

- Gentle ease (360 ms, CSS 'ease') and a soft spring (220 / 22).
- Very large radius (22 px), wide diffuse shadow (10 / 30 px at 8%), light highlight (15%).
- Lighter weight (450), slightly open tracking (+0.01 em), lower contrast (80%).

## Do

- Round inner corners too: inner radius = outer radius minus padding.
- Use tinted, warm neutrals rather than pure grey.

## Don't

- Sharp corners anywhere, including inputs and chips.
- Hard, dark shadows.

**Blends well with:** calm, playful, premium.
**Pulls against:** precise, bold. Blending is allowed; the engine averages each value, so the result sits between the two.
