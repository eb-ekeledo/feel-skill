# Premium

Expensive, considered, unhurried. Like a heavy door that closes softly.

Exact values: run `node scripts/feel.js premium` (intensity 1 to 3 with `--intensity`).

## Signature moves

- Long ease-out (320 ms) with a fast start and a very slow settle: things arrive, they don't bounce.
- Larger radius (14 px) and a deep, soft shadow (12 / 32 px at 12%) so surfaces float.
- Barely-there press (0.985): premium objects don't squish.
- Slight negative tracking (-0.01 em) and a wider type scale (1.25) for confident headings.
- More padding (20 px). Space is the luxury.

## Do

- Use one accent at most. Let materials (shadow, highlight) carry the polish.
- Keep motion on transform and opacity only, so it stays smooth.

## Don't

- Bouncy springs or overshoot. Premium never wobbles.
- Harsh borders, pure black shadows, or crowded layouts.

**Blends well with:** calm, quiet, precise.
**Pulls against:** playful (bounce), bold (hard contrast). Blending is allowed; the engine averages each value, so the result sits between the two.
