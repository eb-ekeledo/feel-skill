# Playful

Bouncy, friendly, a little cheeky.

Exact values: run `node scripts/feel.js playful` (intensity 1 to 3 with `--intensity`).

## Signature moves

- Overshooting curve (y up to 1.56) and a low-damping spring (500 / 14) so things land with a bounce.
- Big radius (20 px), deep press (0.92), visible shadow (6 / 14 px at 14%).
- Heavier type (650) with a wide scale (1.3) for chunky headings.

## Do

- Save the bounce for moments of delight: success, adding, completing.
- Keep durations under 300 ms so bounce never feels slow.

## Don't

- Bouncing everything, including errors and destructive actions.
- Pairing with tiny radius or thin type. It reads as broken, not playful.

**Blends well with:** tactile, bold, soft.
**Pulls against:** premium, precise, calm. Blending is allowed; the engine averages each value, so the result sits between the two.
