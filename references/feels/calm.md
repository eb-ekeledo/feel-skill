# Calm

Slow breath. Nothing demands attention.

Exact values: run `node scripts/feel.js calm` (intensity 1 to 3 with `--intensity`).

## Signature moves

- Long, symmetrical ease (420 ms, standard in-out) and a loose spring (180 / 26).
- Almost no press (0.99) and very soft shadows (8 / 24 px at 6%).
- Lower text contrast (78% ink) and lighter weight (450), still above AA.
- Generous padding (22 px) and a gentle type scale (1.15).

## Do

- Reduce the number of things that move at once.
- Prefer fades and small translations over scale.

## Don't

- Overshoot, flashing, attention-grabbing colour.
- Dense tables or tight spacing.

**Blends well with:** soft, quiet, premium.
**Pulls against:** tactile (snappy), bold (loud). Blending is allowed; the engine averages each value, so the result sits between the two.
