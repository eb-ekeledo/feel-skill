# Quiet

Recedes into the background. Lets the content speak.

Exact values: run `node scripts/feel.js quiet` (intensity 1 to 3 with `--intensity`).

## Signature moves

- Short, plain ease (260 ms) and a well-damped spring (260 / 34): motion you barely notice.
- Tiny radius (8 px), faint shadow (2 / 8 px at 4%), no highlight.
- Regular weight (400), open tracking (+0.01 em), the lowest safe contrast (70%, still AA on white).

## Do

- Use for settings, secondary panels, reading surfaces.
- Prefer borders and spacing over shadows.

## Don't

- Decoration of any kind: gradients, glows, bounce.
- Making primary actions quiet. Keep one clear call to action.

**Blends well with:** calm, precise, premium.
**Pulls against:** bold, playful. Blending is allowed; the engine averages each value, so the result sits between the two.
